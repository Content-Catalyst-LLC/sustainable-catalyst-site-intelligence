# v3.23.7 Global Data Truth Audit

The release separates four concepts that were previously easy to conflate: source operational health, geographic eligibility, observed country-linked records, and indicator availability. The coverage matrix exposes each country-source cell using an explicit state and evidence level. Country catalog membership only makes a geography selectable; it does not establish source availability.

The bundled cartographic catalog supplies 177 country and territory geometries. Source policies declare global, country-limited, point, contextual, or platform scope. Runtime country counts can strengthen a cell from contract-only to observed runtime evidence when collectors provide them.
