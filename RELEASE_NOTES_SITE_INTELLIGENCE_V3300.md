# Site Intelligence v4.4.0 — Institutional Workspaces and Review Governance

## Purpose
Extend the existing institutional workspace foundation with portable investigation packages and explicit review governance without requiring public accounts or paid multi-tenant infrastructure.

## Added
- Portable public-safe workspace preview and export contracts.
- Reviewer queues and structured annotations.
- Role-separated preparation, evidence review, and publication approval checks.
- Hash-chained audit previews that do not falsely claim complete institutional history.
- Import compatibility preview with no automatic import or remote write.
- Workspaces-route governance interface in direct and WordPress iframe modes.

## Boundaries
No public contract provisions accounts, authenticates institutions, writes private collaboration records, automatically approves evidence, automatically publishes content, or requires paid hosted collaboration infrastructure.
