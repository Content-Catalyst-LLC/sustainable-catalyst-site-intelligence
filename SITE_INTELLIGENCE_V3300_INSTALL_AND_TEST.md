# Site Intelligence v4.5.0 — Install and Test

Use the release bundle and macOS installer together. The installer verifies SHA-256 checksums, creates an isolated Python environment, runs two deterministic validation passes, promotes the exact Git tree, waits for the Render release gate, and only then identifies the WordPress ZIP for installation.

The v4.5.0 release gate includes Institutional Workspaces and Review Governance, the complete application shell, country-selector interaction, production soak, service-worker closure, and fixed WordPress embed isolation.
