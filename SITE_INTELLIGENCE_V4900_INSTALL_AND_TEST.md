# Site Intelligence v4.15.0 — Install and Test

Use the release bundle and macOS installer together. The installer verifies SHA-256 checksums, extracts the immutable repository, installs validation dependencies in an isolated virtual environment, runs the deterministic verifier, then promotes through the existing GitHub/Render path.

The live gate requires the Marine Biodiversity overview, catalog, bounded acoustic state, readiness contract, and shipped `marine-biodiversity-v4900.js` asset in addition to all inherited ocean/space/platform production gates.

Install the WordPress ZIP only after the live gate reports the exact v4.15.0 Git commit and release ID as ready.
