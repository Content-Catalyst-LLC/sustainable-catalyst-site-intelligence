# Site Intelligence v4.39.0 R1

## Visual Intelligence Console & Integrated Live Ticker

This presentation-only revision makes `[sc_site_intelligence_home]` feel like a working intelligence surface while preserving the certified v4.39.0 backend contract and WordPress release-gate identity.

### New presentation

- A tighter responsive two-column console layout.
- High-resolution Earth, Space, and Ocean scientific imagery in a compact triptych.
- A restrained green orbital/network overlay that communicates connected capability without implying mapped observations.
- Visible capability labels for Geographic, Earth systems, Ocean, and Orbital work.
- The original governed Live Intelligence ticker embedded directly in the console.
- Existing ticker pause, focus/hover pause, reduced-motion, mobile, freshness, source, and detail-link behavior remains intact.
- The automatic top ticker is suppressed when `[sc_site_intelligence_home]` is present, preventing duplication.

### Data and truth boundaries

- Coverage metrics remain derived from the country and source registries.
- Signal cards remain bounded to the public homepage summary response.
- The imagery demonstrates platform domains; it is not represented as a live observation or current event.
- Image credits are visible in the component.
- Failed summary requests continue to show no estimated counts or fabricated signals.

### Release identity

Both backend and WordPress plugin remain `4.39.0`. The Git tag is `v4.39.0-r1`, so this visual refinement does not create another backend/plugin mismatch.
