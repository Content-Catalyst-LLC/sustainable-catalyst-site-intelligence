# v4.24.0 Biodiversity, Species Distribution & Conservation Audit

- Route architecture: unchanged (six primary areas / 35 public routes).
- Source classes: GBIF, OBIS, eBird, USFWS ECOS.
- Occurrence evidence remains distinct from population abundance and current occupancy.
- Zero-result queries never become absence findings.
- eBird observations never become breeding confirmation or exhaustive census.
- ESA status remains explicitly U.S.-jurisdictional and is not mapped to a global conservation category.
- Critical-habitat spatial overlap never becomes a project-effects or legal determination.
- Dataset/source licensing and provenance fields remain visible in normalized records.
- No IUCN API dependency is included because current IUCN API terms prohibit commercial use.
