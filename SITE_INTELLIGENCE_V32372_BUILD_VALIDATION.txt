Site Intelligence v3.24.0 build validation
Release: Country Dropdown Interaction and Focus Safety
Package state: repaired validator; internal release identity unchanged

Root cause reproduced
- The native country selector received focus and then lost it to #viewTitle approximately 250 ms later.
- Repeated scsi:workspace-state events from background production-truth evaluation retriggered route-heading focus.
- Native browser option menus closed when the selector lost focus, preventing mouse-wheel, trackpad, touch, and keyboard navigation.

Implemented repair
- Form-control focus is protected during background workspace, map, truth, and recovery updates.
- Route-heading focus is deduplicated and runs only for genuine route changes.
- Browser-managed scrolling and keyboard behavior are explicitly preserved for #countrySelect.
- Direct-shell and WordPress-iframe behavior use the same repaired reliability runtime.

Validator repair
- Removed nonportable Home/End assertions for a closed native select in headless macOS Chrome.
- Added unique-catalog, enabled/visible control, pointer-events, uncancelled wheel-event, focus-retention, first-option, last-option, and Brazil-selection checks.
- The failed installer never reached GitHub, Render, or WordPress promotion, so the internal version remains 3.24.0.
