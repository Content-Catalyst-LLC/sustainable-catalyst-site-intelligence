# Install and test v4.35.11
Run `deploy_and_validate_site_intelligence_v4_35_11_macos.sh` with the v4.35.11 release bundle. For full official Energy coverage configure `SC_SI_EIA_API_KEY`, `SC_SI_EMBER_API_KEY`, and `SC_SI_ENTSOE_SECURITY_TOKEN` in Render. These credentials are server-side only and are not required for deployment integrity.
