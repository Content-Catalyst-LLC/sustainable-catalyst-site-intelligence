# Install and Test — Site Intelligence v3.26.0

1. Place the release bundle and macOS installer in `~/Downloads`.
2. Run the installer command provided with the release.
3. The installer verifies checksums, creates an isolated Python environment, runs two complete deterministic validation passes, promotes the exact Git tree, and waits for the Render release gate.
4. Install the WordPress ZIP only after the live gate reports success.
