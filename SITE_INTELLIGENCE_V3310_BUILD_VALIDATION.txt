Browser validation is executed as a package-build gate. Installer validation intentionally does not nest Chromium inside the larger deployment verifier because successful Chromium child processes can linger during teardown and create false installer hangs. The installer instead verifies the immutable package, executes all backend regression tests in a clean virtual environment, and verifies the deployed Render runtime after promotion.

Production deployment is not performed by the build environment.
