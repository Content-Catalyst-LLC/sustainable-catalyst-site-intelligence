# Site Intelligence v4.46.0 — Unified Spatial Evidence Object & Layer Registry

This release establishes the cross-domain spatial evidence foundation for the next Site Intelligence analytical series. It adds a canonical evidence object and source-controlled layer registry without duplicating domain datasets or breaking the existing v2.15 spatial studio.

## Major changes

- Canonical spatial evidence object with geometry, bbox, time, source identity, provenance, quality, visibility and content digest.
- 18-layer cross-domain registry spanning environmental systems, infrastructure, human settlements, oceans, country context and live events.
- Queryable modular FastAPI registry/discovery/normalization/validation routes.
- Capability Registry v1.3.0 with first-class spatial evidence ownership.
- Legacy spatial studio compatibility preserved.
- Contabo promotion contract expanded from 27 to 28 release-bound static files.
