## Implemented renderer (separate release ZIP, 32 unit tests)

`src/native_spatial.py`: owner/project identity, original SI research-object JSON digest recomputation, source artifact SHA, rights/date/CRS provenance, region guard, safe path/size/geometry checks, denial of unapproved point locations and simulated publication. `src/render_native.py`: native publication-sized SVG/PNG rendering of original source GeoJSON, optional vetted EPSG:4326 DEM, dated frames for explicit original time slice IDs. With no DEM, output is 2D/static or 2D+time, **not 4D**. With DEM and at least two frames, output is correctly labelled **terrain and time (2.5D map frames)**, not interactive 4D. `src/publication_bridge.py`: project-owned, hash-pinned saved-object provider and immutable publication revision-service protocols; not a live API route.

No additional application, auth, image-generation provider, DB table, research repository, WordPress plugin, Caddy route or Compose-stack replacement is authorized. The Raspberry Pi is development/staging; Contabo production stays unchanged.
