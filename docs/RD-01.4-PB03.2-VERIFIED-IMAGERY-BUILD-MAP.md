## Scientific and rights release policy

**Review artifacts**: allowed after integrity check, but labels must remain visible. May be archived under private research subject to ownership checks.

**Research-approved assets**: require raw source verified, source-specific rights, meaningful area/date/resolution, actual cloud or radar quality assessment, approved geographic boundary or explicit regional-only label, and human scientific review.

**Publication-ready assets**: additionally require signed Workspace owner/project binding, immutable revision, recorded citations/figure notes, and actual DOCX/PDF render acceptance. No untrusted client `approved=true` flag upgrades asset status.

**Net carbon removal**: no satellite figure proves it. MRV needs controls, biogeochemical evidence, downstream carbon fate, acid corrections and lifecycle emissions.

## Trusted service integration design

Use the existing read-only spatial object composer and artifact contract from SI v4.51. The source-processing module is *not an HTTP endpoint* because it accepts local file paths. The future server must resolve **opaque owner-authorized artifact IDs** to content-addressed bytes and check source SHA on every read; never accept a browser-provided filesystem path, raw session subject or privileged project ID without authorization. Publish via existing RD-01.2/01.3 Studio with signed-session validation and no cross-owner metadata leaks.

## Platform ownership

- Site Intelligence owns provider observation and original / derivative geospatial lineage.
- Workbench / Lab own scientific calculations and their graph records.
- Workspace owns private research projects, revisions and access control.
- Publication Studio owns document assembly, validated figure insertion and exports.
- Historical Wexford restoration is separately grant-restricted and is not a project-creation shortcut.
