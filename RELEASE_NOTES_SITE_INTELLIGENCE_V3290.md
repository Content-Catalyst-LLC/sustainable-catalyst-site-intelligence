# Site Intelligence v4.2.0 — Briefing, Story Map, and Publication Studio

## Purpose
Turn reviewed Site Intelligence evidence into durable publication-ready packages without hiding sources, methodology, limitations, uncertainty, corrections, or the requirement for human editorial approval.

## Added
- Public publication-studio contract and browser panel.
- Frozen source/evidence manifests with SHA-256 change fingerprints.
- Briefing previews with methodology and limitations sections.
- Story-map previews with visual accessibility checks and explicit non-causation boundary.
- Publication-readiness review that never authorizes publication by itself.
- Version-preserving correction, supersession, and retraction previews.
- JSON, Markdown, print-HTML, and evidence-CSV package contracts.
- Accessible-PDF source readiness without falsely claiming that a PDF binary was generated.
- Live deployment gate checks for the new publication-studio runtime.

## Editorial boundaries
No public preview endpoint writes a publication. Human editorial review and explicit publish confirmation remain mandatory. Fingerprints detect changes but do not prove accuracy or authority. Prior public versions are preserved when corrections, supersessions, or retractions are prepared.
